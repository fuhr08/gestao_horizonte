# Gestão Horizonte

Protótipo de um Sistema de Gestão Empresarial para a **Horizonte Soluções**, desenvolvido como projeto acadêmico de Git e GitHub.

## Sobre o projeto

A Horizonte Soluções é uma empresa fictícia que vende produtos e presta serviços. Com o crescimento, seus colaboradores passaram a controlar clientes, produtos, pedidos e relatórios por meio de anotações e planilhas separadas, o que gerou cadastros duplicados e informações desencontradas.

Este repositório reúne um protótipo navegável que mostra como esses setores poderiam ser organizados em um único sistema. Os dados são fictícios e nenhum formulário grava informações.

## Objetivo e funcionalidades previstas

O objetivo é apresentar páginas simples, conectadas entre si e com identidade visual coerente, documentando o desenvolvimento no Git e no GitHub.

Funcionalidades previstas: painel inicial, clientes, produtos, pedidos e relatórios.

## Tecnologias e requisitos

- HTML5 e CSS3
- Git e GitHub
- Para visualizar: um navegador web, sem backend nem banco de dados

## Como obter e abrir o projeto

1. Clone o repositório:

```
   git clone https://github.com/fuhr08/gestao_horizonte.git
```

2. Entre na pasta `gestao_horizonte`.
3. Abra o arquivo `index.html` no navegador.
